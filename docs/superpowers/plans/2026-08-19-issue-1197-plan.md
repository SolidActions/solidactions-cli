## Problem

`completeLogin` (`src/commands/login.ts`) prints `Logged in successfully!` plus the
full "Next step" / "Quick start" block unconditionally — even when the interactive
workspace picker was cancelled (EOF), so `config.workspaceId` is unset and every
suggested next command (`project deploy`, `run start`) will fail.

Secondary (same issue body): the existing-config overwrite confirm is asked *after*
the user has read the picker and answered it. "Ask that first."
